# NOVA - AI Productivity Platform

A modern, fully responsive AI productivity platform landing page built as a Front-End Development Intern Assignment. NOVA helps teams manage projects, automate repetitive tasks, and collaborate efficiently.

## ✨ Features
- **13 Complete Sections:** Navigation bar, Hero dashboard mockup, Company logos, 6 Core features, Product overview, How it works, Animated stats, Department use cases, 3 Testimonials, 3 Pricing tiers with monthly/annual toggle, 5 FAQ accordions, Final CTA with newsletter validation, and Footer.
- **Dynamic Interactions:** Mobile hamburger menu, smooth section scrolling, FAQ accordion dropdowns, and interactive demo modal.
- **Dark / Light Mode:** Fully reactive theme switcher built directly into the navigation bar.
- **Responsive Layout:** Optimized for desktop, laptop, tablet, and mobile devices without horizontal scrolling or layout breaks.

## 🛠️ Technologies Used
- **React (with Vite)** for component-driven UI architecture.
- **Tailwind CSS** for rapid, utility-first styling, glassmorphism, and responsive design.
- **JavaScript (ES6+)** for state management and interactive logic (`useState`, `useEffect`).
